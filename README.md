# Autoclicker

A simple and lightweight autoclicker for macOS, built using the Applications framework.

## Features

- Fast and minimal
- Designed specifically for macOS
- Easy to use and set up

## Requirements

- macOS (tested on MacOs 12.7.6 )
- Accessibility permissions enabled for the app
